基线 `aefdab427ef90bf53f4f83c3713994735b582488`。每一行对应一个前端可交付的数据能力，`metricIds` 引用 [指标字典](03-metrics-dictionary.md) 的稳定 ID。来源与覆盖分开记述。源码范围为当前基线，真实样本见 [对账附录](appendix-verification.md)。机器版 [capability-matrix.json](capability-matrix.json) 与本表同源。

等级表示最小实现层级：L0 消费现有接口，L1 基于现有响应派生，L2 扩展读取或 API，L3 扩展采集、存储或同步，L4 引入独立数据领域。单日分 L1 日摘要、L2 切分与会话查询、L3 有历史可信度承诺的小时桶。若仅面向本地、仅展示具有可证明区间的子集，小时试读可作为 L2 单独发布。
