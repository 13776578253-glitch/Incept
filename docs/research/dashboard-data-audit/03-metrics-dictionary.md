# 指标字典

基线 `aefdab427ef90bf53f4f83c3713994735b582488`。以下公式针对同一时间窗、同一权限投影和同一去重后集合。机器版见 [metrics-dictionary.json](metrics-dictionary.json)，改造等级和各图的数据输入见 [能力矩阵](07-data-capability-matrix.md)。

- `I` 普通输入、`R` 缓存读取、`W` 缓存创建、`O` 输出、`Q` 推理、`T=I+R+W+O+Q`、`P=I+R+W`。`C` 必须先指定费用口径，`U` 为对应口径下未定价 Tokens。
- Usage 在归一化、去重与窗口裁剪后，仅聚合 `T>0` 的事件。日与月按事件的日键、月键入桶，同一已发布 revision 的同窗口可加。会话以设备、来源和会话 ID 组合去重，跨维度依赖集合并集。
- 百分比为小数。区间或筛选改变后使用 `Σ分子/Σ分母`，包括全局缓存命中率、模型缓存命中率和生成／输入比。只在同一个分母下加模型份额。推荐把空分母编码为 `null`，继续兼容旧接口的 0。
- 平台原始字段的包含关系、缺失值及回退来源见 [采集字段表](02-collector-capabilities.md)。Codex 与 CommandCode 从原始输入扣缓存读取，Codex 从输出拆推理。Codex 本地真实样本含写缓存字段，当前归一化固定为 0。Gemini 原始日志还含 tool 和 total，当前五分量无法直接等同于这些原始计数。迁移时先在副本跑同源对账，再添加有版本的统计响应。保留旧口径和版本说明直到前端及历史对比切读。
- 旧 Token Type 图将 `reasoningTokens + cacheCreationTokens` 合入推理显示桶。五桶显示直接使用五个字段。Owner Billing 调和使用估分的模型日费用需要携带方法标志，或只展示 Billing 可直接核对的维度。详见 [界面清单](appendix-ui-inventory.md) 与 [身份和计价](04-identity-and-billing.md)。
