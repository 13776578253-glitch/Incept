## 3. 执行顺序

1. `git push origin main`（本地两次提交）
2. 本机 `docker buildx build --platform linux/amd64 --load -t incept-v4-release:20261025 .`
3. `docker image save` → scp → 服务器 `sha256sum -c` → `docker image load`（两端 image ID 一致）
4. 传运维包并解包到新 release 目录，`compose.sh config --quiet` 预检通过
5. 维护窗口：备份 env → `compose.sh stop app` → `--profile ops run --rm migrate`（**No pending migrations to apply**）
6. 改 `INCEPT_APP_IMAGE` → `current` 指向新目录 → `up -d --wait --wait-timeout 120 app`
7. app healthy 后再 `up -d --wait --wait-timeout 120 sync-gateway`
8. `up -d --no-deps --force-recreate proxy`（让 Caddy 重新解析 app 容器地址）

compose 本次唯一的配置差异是新增 `INCEPT_SYNC_TRUSTED_MODE` 透传，默认 `0`，与本机 env 无该键时行为一致。
