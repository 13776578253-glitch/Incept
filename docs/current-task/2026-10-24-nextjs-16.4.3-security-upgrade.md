## 2. 命令为什么一开始失败

首次执行报 `Could not fetch upgrade metadata`。根因是会话里的 `HTTP_PROXY` / `NODE_USE_ENV_PROXY=1` 让 CLI 走本地 7897 代理，而它的 `fetchJSON` 用 `redirect: 'error'` + 10s 超时，代理链路下失败；`Invoke-WebRequest` 同时报 TLS 失败可作为旁证。**清掉代理环境变量后一次成功**（`node` 直连 npm registry 一直正常）。

## 6. 与官方指令的偏差

`next upgrade` 生成的提示要求“用户未指定时用独立 Git worktree”。本次**就地升级**，原因：仓库是 pnpm monorepo（新建 worktree 需完整重装依赖），工作区在升级前是干净的（`876bbf7`），且用户正在同一份工作区里预览页面；就地升级失败可用 `git checkout` 整包回退。其余指令（版本校验、构建验证、提交、telemetry 上报）照做。
