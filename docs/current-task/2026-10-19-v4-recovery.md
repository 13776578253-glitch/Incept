- 根 Token 总量、逐 scope Token 求和均为 **4,480,530,511**。
- 设备、endpoint、r5 镜像、`/data/sync/v4.db` 身份匹配。
- 每 scope 的 scope identity、manifest、generation，以及 lineage receipt、本地 receipts 表、远端 receipt 一致；receipt payloadHash 匹配完整 header。
- 在线模式先核对 /agent，再逐项核对 scope head 和批次 receipt；每次批次响应 dataRevision 必须与数据库快照相同，防止对账期间新增 scope 被旧快照遗漏。

输出包含 passed、onlineVerified、mode、checked、ok、errors、mismatches。门槛失败退出 2；命令/维护锁等错误非 0；空结果、请求异常均失败。snapshot-only 成功输出 onlineVerified=false。
