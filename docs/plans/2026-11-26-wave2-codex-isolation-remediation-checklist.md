1. **绝不直接改生产库或在线 Agent 状态**；所有排查先读本机原始 Codex JSONL 与 `.scratch/wave1-rehearsal-20261126/v4-wave1.db` 隔离副本。
2. **输出严格脱敏**：写入 `docs/research/` 的报告只使用审阅别名（`S01`–`S18`）或 12 位短哈希，不泄露原始会话路径、Prompt 正文或敏感环境变量。
3. **每修复一个会话，必须给出四项证据**：
   - V4 现有条数 / Tokens vs 本机 JSONL 逐行核验后的有效条数 / Tokens；
   - 异常行定位（行号、时间戳、原因：坏 JSON / 计数器归零 / 计数器跳变 / 重复 ID / 缺前缀）；
   - 拟采用的合法恢复路径（`recoveryRanges` / `rebase-scope` / 维持现状丢弃）；
   - 在 `v4-wave1.db` 隔离副本上执行后的五类 Token 净差、`PRAGMA quick_check` 及二次预演零增量校验。
