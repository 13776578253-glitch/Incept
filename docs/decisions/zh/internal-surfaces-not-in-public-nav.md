# 内部界面不进入前台导航规则

## 目标

当前阶段全力收敛 `docs` 前台阅读界面。

第一阶段前台导航只保留：

- `Docs`
- `About`

其他仍在开发、验证或管理用途中的页面，统一视为内部能力，不出现在前台导航中。

这些页面不删除，保留直接链接访问，用于开发、验证、导入、管理和后续 create/admin 工作流。

## 更新 2026-09-23：`atlas`（图谱）栏目进入前台导航

这条决策本来就有明确的退出路径，走完它的是如今的 **`atlas`（图谱）** 栏目。命名在同一轮内试了三次，全部发生在提交之前；这个序列值得记下来，因为前两次的错法各自有教益：

1. `workspace`（工作台）——已挂载，随后被否。"工作台"承诺的是"干活的地方"，而栏目里放的是看内容的小界面。这个词也已被占用：`WorkspaceShell` 与 `page-shell-workspace` 是 `/studio/docs/library` 在用的共享工具壳。
2. `tools`（工具）——已挂载，随后被否。"工具"是**按容器里装的东西的种类**来命名容器，这正是它怎么都不贴的原因：回放和架构图不是拿起来干活的器械，而是看内容的方式。这个栏目的成员不共享容器类型，它们共享的是**与已有内容的关系**。
3. `atlas`（图谱）——保留。栏目里装的是项目的图：结构、时间、主题。每一项都是从**已经存在**的材料里派生出一个视图，而不是产出新材料。

改名留下了两条重定向，而不是断链，因为前两个路径都曾真实可达：`/workspace → /atlas`、`/tools → /atlas`，三条存续路由另有 `/tools/<旧段> → /atlas/<段>`。

改名期间 **`playback`（回放）被整体移出了本栏目**。它是唯一不贴群的一项：听内容不是阅读项目的方式。它的导航项现在指向 `/settings`——播放偏好与曲库本来就在那里——`/tools/playback` 也重定向过去。

这次修订保持原边界，而不是放宽它：

### 更新 2026-09-27：路线图与图谱分面

路线图是项目的工作跟踪面，图谱是项目内容的派生阅读面。两者在项目导航中是两个并列入口；路线图不再作为图谱总览中的一张卡片。图谱总览当前只列架构和关键词等项目图，路线图固定进入 `/atlas/roadmap?project=<key>`。因此本页早期关于“三个图谱页面”和把 `/atlas/roadmap` 列入图谱清单的描述由本裁定取代。

- 该栏目**不**承载 docs 后台数据。`/studio/docs/library` 保持隐藏，没有任何卡片链接它。
- 该栏目是导航面，不是第二个内容库。它列出 `/atlas/architecture`、`/atlas/roadmap`、`/atlas/keywords`，此外不指向自己子树以外的任何页面。
- 它不新增任何数据访问。总览页是静态入口清单，不读数据库，也不需要 viewer。
- **三个图谱页面都尚未实现。** 每个都是明确的"尚未实现"占位页，且其卡片上都有一行说明该图计划画什么。路由与导航入口先存在，是为了把结构定下来；没有任何占位页声称自己能工作。
- 播放器在 `/atlas` 仍被隐藏（`features/music-player/adapter/player-route-policy.ts`）。这次只改了该路由的前台状态，没动播放器策略。

下文关于其余隐藏界面的内容仍然全部有效。

## 更新 2026-09-23：`roadmap`（路线图）图重定位为人写内容的跨项目集成界面

`roadmap`（路线图）条目在其任何数据工作开始之前被重定位。路线图存储的是人写的内容——高度抽象、跨项目的集成界面——不从任务记录派生。其完整定义在 `docs/decisions/roadmap-integration-surface.md`。本更新逐条处置它触及的先前表述：

- **作废：整句「任何无法被描述为"从已有内容派生的一个视图"的条目，都不属于这里。」** 替换为：条目合格的条件是——它是对独立于该图本身而存在的材料所作的视图，包括保存在本栏目之外存储通道里的人写路线图条目。图自身仍然不产出任何材料；著述发生在别处。
- 2026-09-23 条目中的「它不新增任何数据访问。总览页是静态入口清单，不读数据库，也不需要 viewer。」只对总览页继续成立。`/atlas/roadmap` 将经其包端口读取人写内容存储；viewer 与可见性策略随存储一并裁定。
- **扩展而非放宽：挂载诚实规则「入口可以早于图谱实现挂载，前提是它的卡片与它的页面都明确写出该图尚未实现。」** fixture 作为数据源且存储尚未接通期间，卡片与页面都必须标注"示例数据，尚未接入存储"。存储落地前不得声称已接入。
- **维持并绑定：「docs 后台仍留在 `studio`，不得被挪回图谱栏目」与「它列出 `/atlas/architecture`、`/atlas/roadmap`、`/atlas/keywords`，此外不指向自己子树以外的任何页面」。** owner 门控著述面无论何种形态，都留在 studio/内部路径：绝不进入 atlas 子树，绝不从 atlas 卡片链接。
- **登记：由「若今后还想再放一个非"图"的条目，那就是该重新审视这个栏目是否仍然成立的时点。」点名的重新审视。** 跨项目集成界面拉伸了"项目的图"的定位，正是这句话预留的时点。重新审视就此提起；路线图留在 `/atlas/roadmap` 还是成为顶级界面，在模块的存储 gate 裁定。在此之前路由与导航不动。
- 图谱卡片上承诺里程碑"直接读自任务记录"的注记在本更新落档同轮纠偏；不留卡片宣传已放弃做法的窗口。
- 播放器在 `/atlas` 仍被隐藏（`features/music-player/adapter/player-route-policy.ts`）。本更新不动播放器策略。

## 前台导航规则

前台导航中暂不展示：

- `Resources`
- `Docs archive`
- `Docs style lab`
- `Import preview`
- `Docs library`
- `Docs admin`

`Workspace` 原在此列表内；现在它已成为前台的 `Atlas`（图谱）栏目，见上方更新。

相关文案可以继续保留在 messages 中，避免后续恢复或重组入口时丢失上下文。

导航代码中可以用 `// 并掉代码` 或 `TODO` 注释保留原入口，明确这些能力是“暂不挂前台”，不是彻底废弃。

## 当前内部界面

### Docs Style Lab

本地地址：

```text
http://localhost:3000/en/docs/style-lab
```

职责：

- 用于验证 docs block system 的阅读样式。
- 用于对比 paragraph、heading、list、checklist、callout、quote、divider、code、image 等 block 的渲染效果。
- 用于 create / AI 格式选择前的样式基准验证。

前台状态：

- 不进入前台导航。
- 仅通过直接链接访问。

### Docs Import Preview

本地地址格式：

```text
http://localhost:3000/en/docs/import-preview/{draftId}
```

职责：

- 用于预览 importer 生成的导入草稿。
- 展示源文件路径、目标路由、导入模式、校验结果和最终阅读效果。
- 用于人工确认导入前的 review。

前台状态：

- 不进入前台导航。
- 仅通过导入流程生成的 draft 链接访问。

### Docs Import Confirm

本地地址格式：

```text
http://localhost:3000/en/docs/import-preview/{draftId}/confirm
```

职责：

- 用于确认导入草稿。
- 属于 import preview 的后续动作入口。

前台状态：

- 不进入前台导航。
- 不作为普通页面入口暴露。

### Docs Library

本地地址：

```text
http://localhost:3000/en/studio/docs/library
```

职责：

- 用于查看当前 docs 内容库概览。
- 用于展示 docs article / collection 的管理视图。
- 属于后续 create/edit/publish/admin 工作流的前置管理界面。
- 已从 `workspace` 中移出，归入隐藏的 `studio` 管理界面。

前台状态：

- 不进入前台导航。
- 仅通过直接链接访问。

## 当前策略

这些页面当前全部视为内部能力：

- 可以保留路由。
- 可以保留文案。
- 可以保留开发入口。
- 不挂载到 public site navigation。
- 不作为第一阶段公开产品体验的一部分。

第一阶段公开体验只围绕 docs 阅读界面推进。
